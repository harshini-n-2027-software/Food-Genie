🚀 Project Showcase | Food-Genie

Excited to showcase Food-Genie, a full-stack MERN Stack food recipe discovery application designed to provide users with an interactive and user-friendly recipe experience.

💻 Tech Stack:
React.js | HTML5 | CSS3 | JavaScript | Node.js | Express.js | MongoDB

🔧 Key Features:

🍽️ Food & recipe discovery

🥕 Detailed ingredients for each recipe

👨‍🍳 Step-by-step preparation instructions

🔗 RESTful API integration

🗄️ MongoDB-based data management

📱 Responsive and user-friendly interface

📚 Learning Outcome:
This project strengthened my practical knowledge of MERN Stack development, REST API integration, database connectivity, client-server architecture, and full-stack web development.
